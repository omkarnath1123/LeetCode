A gene string can be represented by an 8-character long string, with choices from 'A', 'C', 'G', and 'T'.

Suppose we need to investigate a mutation from a gene string startGene to a gene string endGene where one mutation is defined as one single character changed in the gene string.

	
- For example, "AACCGGTT" --> "AACCGGTA" is one mutation.

There is also a gene bank bank that records all the valid gene mutations. A gene must be in bank to make it a valid gene string.

Given the two gene strings startGene and endGene and the gene bank bank, return the minimum number of mutations needed to mutate from startGene to endGene. If there is no such a mutation, return -1.

Note that the starting point is assumed to be valid, so it might not be included in the bank.

 

Example 1:

Input: startGene = "AACCGGTT", endGene = "AACCGGTA", bank = ["AACCGGTA"]
Output: 1

Example 2:

Input: startGene = "AACCGGTT", endGene = "AAACGGTA", bank = ["AACCGGTA","AACCGCTA","AAACGGTA"]
Output: 2

 

Constraints:

	
- 0 <= bank.length <= 10

	
- startGene.length == endGene.length == bank[i].length == 8

	
- startGene, endGene, and bank[i] consist of only the characters ['A', 'C', 'G', 'T'].

class Solution {
    char[] values = new char[]{'A', 'C', 'G', 'T'};
    public int minMutation(String startGene, String endGene, String[] bank) {
        
        int len = 8;
        Set<Gene> mutations = new HashSet<>();
        for (String mutation : bank)
            mutations.add(new Gene(mutation));
        Set<Gene> visited = new HashSet<>();

        Deque<Gene> queue = new ArrayDeque<>();
        Gene start = new Gene(startGene);
        queue.offerLast(start);
        visited.add(start);

        int size = queue.size(),
            depth = 0;
        while (!queue.isEmpty()) {
            size--;
            Gene poll = queue.pollFirst();
            if (poll.val.equals(endGene)) return depth;

            char[] temp = new char[len];
            for (int i = 0; i < len; i++)
                temp[i] = poll.chars[i];

            for (int i = 0; i < len; i++)
                for (char value : values) {
                    char old = temp[i];
                    temp[i] = value;
                    Gene next = new Gene(new String(temp));
                    if (mutations.contains(next) && !visited.contains(next)) {
                        visited.add(next);
                        queue.offerLast(next);
                    }
                    temp[i] = old;
                }

            if (size == 0) {
                size = queue.size();
                depth++;
            }
        }
        return -1;
    }
    class Gene {
        char[] chars;
        String val;
        public Gene(String gene) {
            this.chars = gene.toCharArray();
            this.val = gene;
        }
        @Override
        public int hashCode() {
            return Objects.hash(val);
        }
        @Override
        public boolean equals(Object obj) {
            Gene that = (Gene) obj;
            return this.val.equals(that.val);
        }
    }
}
