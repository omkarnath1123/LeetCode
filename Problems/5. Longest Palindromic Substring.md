Given a string s, return the longest palindromic substring in s.

 

Example 1:

Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.

Example 2:

Input: s = "cbbd"
Output: "bb"

 

Constraints:

	
- 1 <= s.length <= 1000

	
- s consist of only digits and English letters.

**Solution:**

- [x] [[Two Pointers]]

- If “aba” is a palindrome, is “xabax” a palindrome? Similarly is “xabay” a palindrome?
- Complexity based hint:</br>
If we use brute-force and check whether for every start and end position a substring is a palindrome we have O(n^2) start - end pairs and O(n) palindromic checks. Can we reduce the time for palindromic checks to O(1) by reusing some previous computation.

```java
class Solution {
    int maxLength;
    String res = "";
    public String longestPalindrome(String s) {
        
        maxLength = 0;
        int len = s.length();

        for (int i = 0; i < len; i++) {
            longestPalindromeOdd(s, i);
        	longestPalindromeEven(s, i, i + 1);
        }
        return res;
    }
    private void longestPalindromeOdd(String s, int start) {
    	longestPalindromeEven(s, start, start);
    }
    private void longestPalindromeEven(String s, int start, int end) {

    	int len = s.length();
    	while (start >= 0 && end < len && s.charAt(start) == s.charAt(end)) {
    		start--;
    		end++;
    	}

        if (maxLength < end - start + 1) {
            maxLength = end - start + 1;
            res = s.substring(start + 1, end);
        }
    }
}
```
