Given a string s, return true if the s can be palindrome after deleting at most one character from it.

 

Example 1:

Input: s = "aba"
Output: true

Example 2:

Input: s = "abca"
Output: true
Explanation: You could delete the character 'c'.

Example 3:

Input: s = "abc"
Output: false

 

Constraints:

	
- 1 <= s.length <= 105

	
- s consists of lowercase English letters.

**Solution:**

- [x] [[Two Pointers]]

class Solution {
    public boolean validPalindrome(String s) {
        
        return validPalindromeUtil(s, 0, s.length() - 1, 1);
    }
    private boolean validPalindromeUtil(String s, int start, int end, int skip) {

        int len = s.length();
        while (start < end) {
            if (s.charAt(start) != s.charAt(end)) {
                if (skip == 0) return false;
                return validPalindromeUtil(s, start + 1, end, skip - 1) || validPalindromeUtil(s, start, end - 1, skip - 1);
            }
            start++;
            end--;
        }
        return true;
    }
}
