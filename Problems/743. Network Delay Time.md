You are given a network of n nodes, labeled from 1 to n. You are also given times, a list of travel times as directed edges times[i] = (ui, vi, wi), where ui is the source node, vi is the target node, and wi is the time it takes for a signal to travel from source to target.

We will send a signal from a given node k. Return the minimum time it takes for all the n nodes to receive the signal. If it is impossible for all the n nodes to receive the signal, return -1.

 

Example 1:

Input: times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
Output: 2

Example 2:

Input: times = [[1,2,1]], n = 2, k = 1
Output: 1

Example 3:

Input: times = [[1,2,1]], n = 2, k = 2
Output: -1

 

Constraints:

	
- 1 <= k <= n <= 100

	
- 1 <= times.length <= 6000

	
- times[i].length == 3

	
- 1 <= ui, vi <= n

	
- ui != vi

	
- 0 <= wi <= 100

	
- All the pairs (ui, vi) are unique. (i.e., no multiple edges.)

**Solution:**

- [x] [[Depth First Search]]

class Solution {
    Map<Integer, List<Integer>> graph;
    Map<Edge, Integer> costs;
    public int networkDelayTime(int[][] times, int n, int k) {
        
        graph = new HashMap<>();
        costs = new HashMap<>();

        for (int[] time : times) {
            int source = time[0],
                dest = time[1],
                cost = time[2];

            graph.putIfAbsent(source, new LinkedList<>());
            graph.get(source).add(dest);
            costs.put(new Edge(source, dest), cost);
        }

        Set<Integer> visited = new HashSet<>();
        PriorityQueue<Pair> queue = new PriorityQueue<>();
        queue.add(new Pair(k, 0));

        int time = 0;
        while (!queue.isEmpty()) {

            Pair poll = queue.remove();
            if (visited.size() < n) 
                time = Math.max(time, poll.cost);
            visited.add(poll.node);

            for (int next : graph.getOrDefault(poll.node, new LinkedList<>())) {
                if (visited.contains(next)) continue;
                
                int currCost = costs.get(new Edge(poll.node, next));
                queue.add(new Pair(next, poll.cost + currCost));
            }
        }

        if (visited.size() == n) return time;
        else return -1;
    }
    class Edge {
        int start, end;
        public Edge(int start, int end) {
            this.start = start;
            this.end = end;
        }
        @Override
        public int hashCode() {
            return Objects.hash(start, end);
        }
        @Override
        public boolean equals(Object obj) {
            Edge that = (Edge) obj;
            return this.start == that.start && this.end == that.end;
        }
    }
    class Pair implements Comparable<Pair> {
        int node, cost;
        public Pair(int node, int cost) {
            this.node = node;
            this.cost = cost;
        }
        @Override
        public int compareTo(Pair that) {
            return Integer.compare(this.cost, that.cost);
        }
    }
}
