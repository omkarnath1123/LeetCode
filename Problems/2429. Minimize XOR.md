Given two positive integers num1 and num2, find the positive integer x such that:

	
- x has the same number of set bits as num2, and

	
- The value x XOR num1 is minimal.

Note that XOR is the bitwise XOR operation.

Return the integer x. The test cases are generated such that x is uniquely determined.

The number of set bits of an integer is the number of 1's in its binary representation.

 

Example 1:

Input: num1 = 3, num2 = 5
Output: 3
Explanation:
The binary representations of num1 and num2 are 0011 and 0101, respectively.
The integer 3 has the same number of set bits as num2, and the value 3 XOR 3 = 0 is minimal.

Example 2:

Input: num1 = 1, num2 = 12
Output: 3
Explanation:
The binary representations of num1 and num2 are 0001 and 1100, respectively.
The integer 3 has the same number of set bits as num2, and the value 3 XOR 1 = 2 is minimal.

 

Constraints:

	
- 1 <= num1, num2 <= 109

**Solution:**

- [x] [[Greedy]]

class Solution {
    public int minimizeXor(int one, int two) {
        
        int bitCountTwo = Integer.bitCount(two);
        boolean[] bitArray = getBitArray(one);

        boolean[] res = new boolean[32];
        for (int i = 0; i < 32; i++) {
            if (bitCountTwo == 0) break;

            int pos = 32 - i - 1;
            if (bitArray[pos]) {
                res[pos] = true;
                bitCountTwo--;
            }
        }

        int index = 0;
        while (bitCountTwo > 0) {
            if (!res[index]) {
                res[index] = true;
                bitCountTwo--;
            }
            index++;
        }

        int num = 0;
        for (int i = 0; i < 32; i++)
            if (res[i])
                num = num + (int) Math.pow(2, i);
        return num;
    }
    private boolean[] getBitArray(int num) {

        boolean[] bits = new boolean[32];
        for (int i = 0; i < 32; i++) {
            bits[i] = (num & 1) == 1;
            num = num >> 1;
        }
        return bits;
    }
}
