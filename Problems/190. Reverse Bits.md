Reverse bits of a given 32 bits signed integer.

 

Example 1:

Input: n = 43261596

Output: 964176192

Explanation:

	
		
			Integer
			Binary
		
		
			43261596
			00000010100101000001111010011100
		
		
			964176192
			00111001011110000010100101000000
		
	

Example 2:

Input: n = 2147483644

Output: 1073741822

Explanation:

	
		
			Integer
			Binary
		
		
			2147483644
			01111111111111111111111111111100
		
		
			1073741822
			00111111111111111111111111111110
		
	

 

Constraints:

	
- 0 <= n <= 231 - 2

	
- n is even.

 

Follow up: If this function is called many times, how would you optimize it?

class Solution {
    public int reverseBits(int n) {
        if (n == 0) return 0;

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 32; i++) {
            boolean isOne = (n & 1) == 1;
            n = n >> 1;
            sb.append(isOne ? "1" : "0");
        }
        String res = sb.toString();
        int start = 0;
        for (int i = 0; i < 32; i++)
            if (res.charAt(i) == '0')
                start++;
            else
                break;

        return (int) Integer.parseInt(sb.substring(start), 2);
    }
}
